FIEF - a wallpaper that builds a kingdom around your icons
===========================================================

Run Fief.exe. A medieval world appears behind your desktop icons:
every group of icons founds a settlement (camp, hamlet, village,
walled town, city). Move, add or delete an icon and the world reacts.

Fief sits near the clock as a small blue shield. Right-click it for
Settings, Screens, Pause, Start with Windows and Quit.

First launch: the program is not signed yet, so Windows may say
"Windows protected your PC". Choose "More info", then "Run anyway".

Requirements: Windows 10 or 11 (64-bit) with the Microsoft Edge
WebView2 Runtime, which ships with up-to-date Windows.

To remove Fief: Quit from the shield icon, then delete this folder.
Settings are stored in %LOCALAPPDATA%\Fief.

Fief only reads the position of your icons - never file names or
contents - and makes no network connection.
